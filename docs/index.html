Code Recorder for STS5

Record code edits and file changes in Spring Tools 5 and export recordings as JSON.

Install

Open Help → Install New Software → Add and enter this update site:

https://pinnpublic.github.io/code-recorder-sts5/updates/

Select Code Recorder for STS5, complete installation and restart the IDE.

Version 0.5.2. Target: Spring Tools 5.2.0.RELEASE / Eclipse 4.40 / Windows / IDE runtime Java 25.

Record

Open Window → Show View → Other → Code Recorder. Select a project or folder, start recording, then use Stop / Export to save the recording.
